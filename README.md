# TokTickIT 🎫

A simple IT Service Desk application built for Software Engineering Lab 1.

## 🛠️ Stack
* **Frontend:** React + Vite, TypeScript, Bootstrap
* **Backend:** Node.js, Express, Prisma ORM
* **Testing:** Vitest & Supertest

## 🚀 How to Run

### Backend
```bash
cd server
npm install
npm run dev

### Frontend
cd client
npm install
npm run dev
